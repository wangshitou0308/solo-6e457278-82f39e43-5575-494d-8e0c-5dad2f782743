# 窑烧程序校对工具（本地 Web）

供陶艺工作室在装窑前**校对窑烧（烧成）程序**的本地单页工具：用「升降温速率 / 目标温度 / 保温时长」编排分段曲线，
编译成控制器可录入的步骤，自动标出超温、能力不足、段数溢出、零时长跳温与取整偏移。

- **不连接窑炉，不连接任何外部平台**，可完全离线使用。
- 服务端仅用 Python 标准库（`http.server` + `sqlite3`），零第三方依赖。
- 浏览器端为原生 HTML / CSS / JavaScript / SVG，无构建步骤。

## 启动

需要 Python 3.8+（标准库即可，无需安装任何包）：

```bash
cd kiln-planner
python3 server.py
```

打开终端中提示的地址（默认 <http://localhost:8000/>）。

可选参数：

```bash
python3 server.py --port 8080          # 换端口
python3 server.py --host 0.0.0.0       # 允许局域网内其他电脑访问（默认仅本机）
python3 server.py --db /path/to.db     # 指定 SQLite 数据文件
```

数据保存在同目录 `kiln.db`。双击直接打开 `static/index.html` 也能完整使用，
此时数据保存在浏览器 localStorage 中（页面底部会提示当前存储方式）。

## 功能

| 区域 | 说明 |
| --- | --- |
| 分段编排 | 每段 = 速率 ℃/h + 目标温度 ℃ + 保温 min；同温段自动视为纯保温。修改任一参数，总时长、各段起止时刻、曲线、编译步骤立即联动。 |
| 图上拖动 | 实心圆 = 升温/降温点（上下改温度、左右改升降耗时，即速率）；空心圆 = 保温结束点（左右改保温）；菱形 = 起始炉温。按住 Shift 按步进吸附。 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`），所有编辑（含窑炉参数、拖动）都可撤销。 |
| 校验问题 | ① 超温（超过窑炉温度上限）② 能力不足（速率超过升降温能力）③ 段数溢出（超过控制器段数）④ 零时长跳温（升降不足 1 分钟）⑤ 取整偏移。点击问题可定位图上节点。 |
| 编译步骤 | 按速率/温度/时长步进就近取整，生成可照抄录入控制器的步骤表；图上实线为原曲线、蓝色虚线为取整后的执行曲线。 |
| 拆段 / 合并 | 段中点一拆为二；相邻两段可合并（保持总时长不变），用于解决段数溢出或调整曲线转角。 |
| 版本与对照 | 一个方案可保存多个版本，可载入旧版，也可任选两版（含当前编辑稿）做参数差异表 + 双曲线对照。 |
| 导入 / 导出 | 方案与窑炉参数打包为 JSON 文件；导入会新建窑炉与方案，不覆盖现有数据。 |
| 打印卡 | 生成 A4 单页程序卡：元信息、注意事项、原/执行双曲线、取整后的步骤表、签名栏。 |
| 多窑炉 | 每台窑炉独立配置温度上限、升降温能力、控制器段数及三个步进值。内置 3 个可编辑示例。 |

## 文件结构

```
kiln-planner/
├── server.py            # 标准库 HTTP 服务 + SQLite API
├── kiln.db              # 首次运行后生成
└── static/
    ├── index.html       # 页面结构
    ├── style.css        # 样式（含 A4 打印样式）
    └── app.js           # 全部前端逻辑（含可离线运行的本地存储回退）
```

## JSON 导入导出格式

```json
{
  "app": "kiln-planner",
  "format": 1,
  "kiln": { "name": "窑炉名", "config": {
    "maxTemp": 1280, "heatRateMax": 150, "coolRateMax": 100,
    "maxSegments": 16, "rateStep": 5, "tempStep": 5, "holdStep": 5 } },
  "plan": { "name": "方案名", "data": {
    "startTemp": 25,
    "segments": [ { "rate": 100, "target": 600, "hold": 0 } ] } }
}
```

也接受只含 `startTemp` + `segments` 的精简文件。
